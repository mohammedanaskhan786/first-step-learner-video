# FIRST STEP LEARNER
## AI Aapse Zyada Smart Nahi Hai… Phir Log AI Se Itna Kaam Kaise Karwa Rahe Hain?

**Production:** Premium 3D Animated Technology Explainer  
**Target Runtime:** ~60 minutes  
**Voice:** Male Hindi/Hinglish  
**Visual Identity:** Black + Purple/Violet, cinematic, futuristic  
**Characters:** No human characters or avatars  
**Presentation:** Islamic-friendly throughout

---

## REMOTION PRODUCTION KEY

Use the following scene markers as the source-of-truth structure for the Remotion composition.

- `SCENE` = new Remotion scene/sequence
- `VO` = voiceover narration
- `VISUAL` = primary visual direction
- `UI` = holographic interface / screen content
- `TEXT` = supporting on-screen text only
- `CAMERA` = camera movement
- `TRANSITION` = transition into next scene
- `SFX` = optional sound-design cue
- `PAUSE` = intentional narration/visual breathing room

**Global visual rule:** captions support the narration; they must not become the main visual content.
